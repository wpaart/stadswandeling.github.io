Add photos to the walk

← Back to the map. Photos are committed straight to your GitHub repository, and GitHub Pages republishes the site within about a minute.

1. Connect to your repository

Use a fine-grained token limited to this one repository with Contents: Read and write. It is kept in this browser only and sent only to api.github.com.

2. Choose photos

GPS coordinates are read from each photo. If a photo has none (many phones strip it when sharing), select it and click the map, drag its pin, or use your current location.

3. Check locations

Select a photo card, then click the map to place it. Drag a pin to fine-tune.

4. Publish
